# Site de Coralie Hirschi – GitHub Pages

Fichiers à ajouter vous-même dans ce dossier :
- photo.jpg  (votre photo de profil)
- CV_2025.pdf (votre CV)

Mise en ligne :
1. Créez un compte sur github.com.
2. Créez un dépôt public nommé exactement : VOTRE-PSEUDO.github.io
3. « Add file » > « Upload files » : glissez tous les fichiers de ce dossier, puis « Commit changes ».
4. Settings > Pages : Source = « Deploy from a branch », branche « main », dossier « / (root) », Save.
5. Après 1 à 2 minutes, le site est en ligne sur https://VOTRE-PSEUDO.github.io

Pour modifier un texte : ouvrez le fichier .html sur GitHub, cliquez sur le crayon, modifiez, « Commit changes ».
